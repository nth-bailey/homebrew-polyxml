# Homebrew Tap for PolyXML

Official Homebrew Tap for **PolyXML** — the high-performance, polyglot native XML data-binding engine built in Rust with modern C++20 and C bindings.

## Installation

```bash
brew install nth-bailey/polyxml/polyxml
```

Or tap first:

```bash
brew tap nth-bailey/polyxml
brew install polyxml
```

## Documentation

For full documentation and multi-language guides, visit [nth-bailey.github.io/PolyXML](https://nth-bailey.github.io/PolyXML/).
